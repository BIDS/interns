# Event Signage Instructions

Interns can find all signage templates in Adobe Express under the **Projects** tab (labeled **BIDS TEAM**).

## Direction Signs

* The template is named **[Template] Direction sign**. Duplicate it before editing.
* Type out the event name where indicated and insert the event logo (found under "Brands" -> "Logos" in the right-hand navigation bar).
* If no event logo is provided, use the BIDS logo that includes "Berkeley Institute of Data Science."

### AIFL
* AIFL uses the Berkeley Secondary Palette (under "Brands" -> "Colors"), so use the yellow background for signs in this location.

### Gateway
* Gateway uses the Berkeley Primary Palette OR the Berkeley Blue-White Palette, so use the gray/white background for signs in this location.

## Welcome Signs (AIFL-only)

These signs are placed in an acrylic sign-holder and brought down to the first floor of the AIFL so the attendant can let in attendees who do not have card access to the building.

* The template is named **[Template] Event Welcome AIFL**. Duplicate it before editing.
* Type out the event name (shorten if needed) and date(s) where indicated, and insert the BIDS logo that includes "Berkeley Institute of Data Science."

## Crowd Photo Release Form

* The template is named **[Template] Crowd Photo Release**. Duplicate it before editing.
* Type out the date where indicated and insert the event logo. If no event logo is provided, center the BIDS logo that includes "Berkeley Institute of Data Science."
* In the text body, replace [Organizers] with the event organizer(s). If the event is held by BIDS, type "BIDS Team."

## Room Signs

* The template is named **Room Names**. Duplicate it before editing.
* Type the location/name of the event.

## Printing

* Download all designs as **PDF Print**.
* For all event signage, use the BIDS printer. The AIFL printer is unreliable.
